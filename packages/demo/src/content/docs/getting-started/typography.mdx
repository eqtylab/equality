## Overview

Use this page to pick a text style for product UI: a page's title, a card's title, a row, a hint. Pick a style by the space the text heads, not by its HTML level. Long-form writing, such as an article or a help page, uses [Heading](/components/heading) instead.

## The Scale

| Style          | Size on line | Weight             | Use for                                           |
| -------------- | ------------ | ------------------ | ------------------------------------------------- |
| `text-title-1` | 28 on 36     | Semibold           | A page's title                                    |
| `text-title-2` | 20 on 28     | Semibold           | The title of a dialog, sheet or tab panel         |
| `text-section` | 16 on 24     | Semibold           | A card or section title                           |
| `text-body`    | 14 on 20     | The text around it | Running text, descriptions, labels and table rows |
| `text-caption` | 12 on 16     | The text around it | Timestamps, counts and hints                      |

Body is Tailwind's `text-sm`, so plain `text-sm` in your app is the same size.

## When to Use Each Style

| If the text heads…                                                   | Use                           |
| -------------------------------------------------------------------- | ----------------------------- |
| A page                                                               | `text-title-1`                |
| A dialog, sheet or tab panel                                         | `text-title-2`                |
| A card or a section of a page                                        | `text-section`                |
| Nothing: it sits inside a card, as a row, field, empty state or tile | `text-body` or `text-caption` |

Put the style on the heading element that fits the page's outline. A card title can be an `h2` and still use section.

### Title 1

A page's title, once per page, in a row with the page's default buttons.

```tsx

```

### Title 2

The title of a dialog, sheet or tab panel: a surface inside the page with its own title. Already styled in `DialogTitle`, `SheetTitle` and `AlertDialogTitle`:

```tsx
<Dialog>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Edit Project</DialogTitle>
      <DialogDescription>Change its name and owner.</DialogDescription>
    </DialogHeader>
  </DialogContent>
</Dialog>
```

Use the class yourself only for a tab panel's title or a surface you build.

## Put a Description Under a Heading

1. Put the heading and its description in a column.
2. Set the gap by the heading: none under a section title, `gap-1` under title-2 and `gap-2` under title-1.

<div className="my-4">
  <TypographyDemo example="spacing" />
</div>

```tsx
<div className="flex flex-col">
  <h2 className="text-section">Recent Activity</h2>
  <p className="text-body text-text-secondary">What changed this week</p>
</div>

<div className="flex flex-col gap-1">
  <h2 className="text-title-2">Edit Project</h2>
  <p className="text-body text-text-secondary">Change its name and owner</p>
</div>

<div className="flex flex-col gap-2">
  <h1 className="text-title-1">Projects</h1>
  <p className="text-body text-text-secondary">Every project your team can open</p>
</div>
```

## Set a Title Beside Buttons

1. Put the title and its controls in one row, centred: `flex items-center`.
2. Use default buttons beside title-1, and small buttons or an `IconButton` at its default size beside title-2 and section.
3. Keep a badge beside a title at its default size.

  <TypographyDemo example="align" />

```tsx

  <h1 className="text-title-1">Projects</h1>
  <Button>New Project</Button>
</div>

<div className="flex items-center justify-between gap-4">
  <h2 className="text-section">Recent Activity</h2>

    See All
```

## Use the Styles with tailwind-merge

1. Register the five styles as font sizes, or a text colour beside them removes them.
2. Keep `title` in the list while your app still uses `text-title`. It's deprecated: use `text-title-1`. 8.0 removes it.

```ts
import { clsx, type ClassValue } from "clsx";
import { extendTailwindMerge } from "tailwind-merge";

const twMerge = extendTailwindMerge({
  extend: {
    classGroups: {
      "font-size": [
        {
          text: [
            "xxs",
            "title",
            "title-1",
            "title-2",
            "section",
            "body",
            "caption",
          ],
        },
      ],
    },
  },
});

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
```

## How the Styles Line Up

Each style's line is one of the [size steps](/getting-started/sizing), the same steps controls use, so text in a row with controls centres on them the way a button centres its label. The page title's line is as tall as a default control, so a page title sits level with the page's buttons without any extra spacing. Title-2's line is as tall as a small control, so a dialog's title sits level with its close button, and a section title's shorter line centres in the same row beside small buttons.

## Do and Don't

- Don't put title-1 inside a card or dialog. It heads the page only.
- Don't size a heading with `text-2xl`, `text-3xl` or a similar size, or add `font-bold`. Use one of the five styles.
- Don't use `Heading` for app screens. It's for long-form writing.
- Don't pick a style by HTML level. Pick it by the space the text heads.
- Don't add `text-title-2` to `DialogTitle`, `SheetTitle` or `AlertDialogTitle`. They have it already.
- Don't use `text-title`. It's deprecated: use `text-title-1`.
