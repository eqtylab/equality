## Overview

Use this page to pick a text style for product UI: a page's title, a card's title, a row, a hint. Long-form writing, such as an article or a help page, uses [Heading](/components/heading) instead.

## The Scale

| Style          | Size on line | Weight             | Use for                                        | Already applied by                                                                                                                                          |
| -------------- | ------------ | ------------------ | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `text-title-1` | 28 on 36     | Semibold           | A page's title, once per page                  | None                                                                                                                                                        |
| `text-title-2` | 20 on 28     | Semibold           | The title of a dialog, sheet or tab panel      | The title in a Dialog, Sheet or Alert Dialog                                                                                                                |
| `text-section` | 16 on 24     | Semibold           | A card or section title                        | [Card Content Header](/components/card-content-header), [Section Heading](/components/section-heading), [Title Block](/components/title-block) at size `sm` |
| `text-body`    | 14 on 20     | The text around it | Text inside a card: rows, fields, descriptions | None                                                                                                                                                        |
| `text-caption` | 12 on 16     | The text around it | Timestamps, counts and hints                   | None                                                                                                                                                        |

Body is Tailwind's `text-sm`, so plain `text-sm` in your app is the same size.

Pick a style by the space the text heads; anything inside a card stays body or caption. Put the style on the heading element that fits the page's outline: a card title can be an `h2` and still use section.

## Build a Page Header

1. Put `text-title-1` on the page's `h1`.
2. Put the title, any `Badge` and the page's buttons in one row, centred.
3. Put the description under that row at `gap-2`.

<div className="my-4">
  <TypographyDemo example="page-header" />
</div>

```tsx
<header className="flex flex-col gap-2">
  <div className="flex flex-wrap items-center justify-between gap-4">
    <div className="flex items-center gap-2">
      <h1 className="text-title-1">Projects</h1>
      <Badge variant="neutral">Beta</Badge>
    </div>
    <div className="flex gap-2">
      <Button variant="tertiary">Import</Button>
      <Button>New Project</Button>
    </div>
  </div>
  <p className="text-body text-text-secondary">
    Every project your team can open
  </p>
</header>
```

## Title a Dialog, Sheet or Tab Panel

1. In a `Dialog`, `Sheet` or `AlertDialog`, use its title and description (`DialogTitle` and `DialogDescription`, `SheetTitle` and `SheetDescription`, `AlertDialogTitle` and `AlertDialogDescription`) inside its header; they're already styled and spaced.
2. For a tab panel or a surface you build, put `text-title-2` on its heading, the description under it at `gap-1`, and small buttons in its row, centred.

<div className="my-4">
  <TypographyDemo example="dialog-header" />
</div>

```tsx
<Dialog>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>New Project</DialogTitle>
      <DialogDescription>
        Name the project and choose who owns it.
      </DialogDescription>
    </DialogHeader>
  </DialogContent>
</Dialog>
```

```tsx
<div className="flex flex-col gap-1">
  <div className="flex items-center justify-between gap-4">
    <h2 className="text-title-2">New Project</h2>
    <IconButton name="X" label="Close" />
  </div>
  <p className="text-body text-text-secondary">
    Name the project and choose who owns it.
  </p>
</div>
```

## Head a Card or Section

1. For a title with See All, use [Card Content Header](/components/card-content-header) in a card or [Section Heading](/components/section-heading) on a page.
2. For a title with a description, put `text-section` on the heading, the description directly under it, and small buttons in the title's row, centred on the title.

<div className="my-4">
  <TypographyDemo example="card-header" />
</div>

```tsx
<div className="flex flex-col">
  <div className="flex items-center justify-between gap-4">
    <h2 className="text-section">Storage</h2>
    <Button variant="tertiary" size="sm">
      Manage
    </Button>
  </div>
  <p className="text-body text-text-secondary">
    Files uploaded to this project
  </p>
</div>
```

## Set Up an App That Merges Classes

1. Register the five styles as font sizes in your `cn`, or a text colour beside them removes them.
2. Move any `text-title` to `text-title-1`. Keep `title` in the list until you have; `text-title` is deprecated, and 8.0 removes it.

```ts
import { clsx, type ClassValue } from "clsx";
import { extendTailwindMerge } from "tailwind-merge";

const twMerge = extendTailwindMerge({
  extend: {
    classGroups: {
      "font-size": [
        {
          text: [
            "xxs",
            "title",
            "title-1",
            "title-2",
            "section",
            "body",
            "caption",
          ],
        },
      ],
    },
  },
});

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
```

## How the Styles Line Up

Each style's line is a [size step](/getting-started/sizing), the same steps controls use, so text centres on the controls in its row.

## Do and Don't

- Don't put title-1 inside a card or dialog. It heads the page only.
- Don't size a heading with `text-2xl`, `text-3xl` or a similar size, or add `font-bold`. Use one of the five styles.
- Don't use `Heading` for app screens. It's for long-form writing.
- Don't use `text-title`. It's deprecated: use `text-title-1`.
