## Overview

Equality has five text styles for product UI. Each pairs a size with a line height, and each line sits on one of the [size steps](/getting-started/sizing).

| Style          | Size on line | For                                                         |
| -------------- | ------------ | ----------------------------------------------------------- |
| `text-title-1` | 28 on 36     | A page's title                                              |
| `text-title-2` | 20 on 28     | The title of a dialog, sheet or tab panel                   |
| `text-section` | 16 on 24     | A card or section title                                     |
| `text-body`    | 14 on 20     | Running text, descriptions, labels and table rows           |
| `text-caption` | 12 on 16     | Small supporting text, such as timestamps, counts and hints |

Title-1, title-2 and section are semibold; body and caption keep the weight of the text around them. For a label that should stay medium, add `font-medium` beside the style. Body is Tailwind's `text-sm`, so plain `text-sm` in your app is the same size.

Long-form writing, such as an article or a help page, uses [Heading](/components/heading) instead.

## Choosing a Style

Pick a style by the space the text heads, not by its HTML level. A page takes title-1. A dialog, sheet or tab panel inside the page takes title-2. A card takes section, and anything inside a card stays body or caption.

Keep the heading element that fits the page's outline, and put the style on it. A card title can be an `h2` and still use section:

```tsx
<h2 className="text-section">Recent Activity</h2>
```

The examples on this page draw their titles as paragraphs to keep this page's outline clean; the code beside each shows the heading to use.

## Lining Up with Controls

Each style's line is one of the size steps, so text in a row with controls centres on them, the way a button centres its label. The page title's line is as tall as a default control, so it sits level with the page's buttons. A card title sits beside a small button the same way, and a dialog's title beside its close button.

## Space Under a Heading

Put a heading's description close to it, and leave more room under bigger headings: none under a section title, 4 under title-2 and 8 under title-1.

```tsx
<div className="flex flex-col gap-2">
  <h1 className="text-title-1">Projects</h1>
  <p className="text-body text-text-secondary">
    Every project your team can open.
  </p>
</div>
```

## Text Styles

### Title 1

Use `text-title-1` for the page title, centred in a row with the page's default buttons.

<TypographyDemo example="title-1" />

```tsx
<div className="flex items-center justify-between gap-4">
  <h1 className="text-title-1">Projects</h1>
  <Button>New Project</Button>
</div>
```

### Title 2

Use `text-title-2` for the title of a dialog, sheet or tab panel: a surface inside the page that needs its own title, a step below the page's. Centre it in a row with any small buttons beside it.

<TypographyDemo example="title-2" />

```tsx
<div className="flex items-center justify-between gap-4">
  <h2 className="text-title-2">Edit Project</h2>
  <IconButton name="X" label="Close" />
</div>
```

### Section

Use `text-section` for a card or section title, centred in a row with any small buttons beside it. [Card Content Header](/components/card-content-header), and [Section Heading](/components/section-heading) without a description, already do this.

<TypographyDemo example="section" />

```tsx
<Card>
  <CardContent>
    <div className="flex items-center justify-between gap-4">
      <h2 className="text-section">Recent Activity</h2>
      <Button variant="tertiary" size="sm">
        See All
      </Button>
    </div>
  </CardContent>
</Card>
```

### Body

Use `text-body` for running text and descriptions.

<TypographyDemo example="body" />

```tsx
<p className="text-body">
  Every model in this project is evaluated against its controls before release.
</p>
```

### Caption

Use `text-caption` for small supporting text, such as a timestamp or a hint under a field.

<TypographyDemo example="caption" />

```tsx
<p className="text-caption text-text-secondary">Updated 2 hours ago</p>
```

## Badge Beside a Title

A badge beside a title keeps its default size and sits centred on the title's line.

<TypographyDemo example="badge" />

```tsx
<div className="flex items-center gap-2">
  <h1 className="text-title-1">Model Registry</h1>
  <Badge variant="neutral">Beta</Badge>
</div>
```

## Merging Classes

If your app merges classes with tailwind-merge, register the five styles as font sizes, or a text colour beside them removes them. Keep `title` in the list while your app still uses `text-title`.

```ts
import { clsx, type ClassValue } from "clsx";
import { extendTailwindMerge } from "tailwind-merge";

const twMerge = extendTailwindMerge({
  extend: {
    classGroups: {
      "font-size": [
        {
          text: [
            "xxs",
            "title",
            "title-1",
            "title-2",
            "section",
            "body",
            "caption",
          ],
        },
      ],
    },
  },
});

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
```
