## Overview

Product UI uses four text styles: title-1 for a page's title, section for a dialog's, sheet's or card's title, then body and caption. Pick a style by what the text heads; text inside a card is body or caption. Title-2 heads a section of long-form writing. Docs and marketing pages add two [display styles](#display-styles) above them. Long-form writing, such as an article or a help page, uses [Heading](/components/heading).

## Scale

| Style          | Size / line height | Weight    | Use for                                        | Already applied by                                                                                                                                                                                                                                     |
| -------------- | ------------------ | --------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `text-title-1` | 28 / 36            | Semibold  | A page's title, once per page                  | [Heading](/components/heading) `h1`                                                                                                                                                                                                                    |
| `text-title-2` | 20 / 28            | Semibold  | An `h2` in long-form writing                   | [Heading](/components/heading) `h2`                                                                                                                                                                                                                    |
| `text-section` | 16 / 24            | Semibold  | A dialog, sheet, card or section title         | The title in a Dialog, Sheet or Alert Dialog, [Card Content Header](/components/card-content-header), [Section Heading](/components/section-heading), [Title Block](/components/title-block) at size `sm`, [Heading](/components/heading) `h3` to `h6` |
| `text-body`    | 14 / 20            | Inherited | Text inside a card: rows, fields, descriptions | None                                                                                                                                                                                                                                                   |
| `text-caption` | 12 / 16            | Inherited | Timestamps, counts and hints                   | None                                                                                                                                                                                                                                                   |

Sizes are in pixels. Body and caption take the weight of the text around them; add `font-medium` for a label that should stay medium. Body is Tailwind's `text-sm`. Put a style on the heading element that fits the page's outline: a card title can be an `h2` and still use section.

### How the Styles Line Up

Each style's line height is a [size step](/getting-started/sizing), the same steps controls use. A text line is the height of one line of text; a row is the height of the controls beside it, and the text is vertically centred in it, so a 24 section line sits in a 28 row with small buttons.

### Typeface

Text is set in TWK Lausanne, falling back to Inter, then the system sans serif. Code is set in IBM Plex Mono.

### Text Colour

| Text                                    | Class                                   |
| --------------------------------------- | --------------------------------------- |
| Titles and content                      | `text-text-primary`                     |
| Descriptions, captions and hints        | `text-text-secondary`                   |
| Links                                   | `text-text-link`                        |
| An error or a warning in a field or row | `text-text-danger`, `text-text-warning` |

Text is primary unless you set a colour.

## Display Styles

Two larger styles for docs and marketing pages only. Never use them in app screens: a product page's title is `text-title-1`.

| Style            | Size / line height | Weight   | Use for                                           |
| ---------------- | ------------------ | -------- | ------------------------------------------------- |
| `text-display-1` | 48 / 52            | Semibold | A landing page's hero, once per page              |
| `text-display-2` | 36 / 44            | Semibold | A docs page's title, or a marketing section title |

Choose them on purpose, on the page that needs them: Heading never applies them.

```tsx
<h1 className="text-display-1">Build with Equality</h1>
```

## Build a Page Header

1. Put `text-title-1` on the page's `h1`.
2. Put the title, any `Badge` and the page's buttons, at their default size, in one row, vertically centred (`items-center`).
3. Put the description under that row at `gap-2`.

<div className="my-4">
  <TypographyDemo example="page-header" />
</div>

```tsx
import { Badge, Button } from "@eqtylab/equality";

<header className="flex flex-col gap-2">
  <div className="flex flex-wrap items-center justify-between gap-4">
    <div className="flex items-center gap-2">
      <h1 className="text-title-1">Projects</h1>
      <Badge variant="neutral">Beta</Badge>
    </div>
    <div className="flex gap-2">
      <Button variant="tertiary">Import</Button>
      <Button>New Project</Button>
    </div>
  </div>
  <p className="text-body text-text-secondary">
    Every project your team can open
  </p>
</header>;
```

## Title a Dialog or Sheet

1. In a `Dialog`, `Sheet` or `AlertDialog`, use its title and description (`DialogTitle` and `DialogDescription`, `SheetTitle` and `SheetDescription`, `AlertDialogTitle` and `AlertDialogDescription`) inside its header. They're already styled and spaced, and a Dialog or Sheet adds its own close button.
2. Title a tab panel or a surface you build like a card or section: see [Head a Card or Section](#head-a-card-or-section).

<div className="my-4">
  <TypographyDemo example="dialog-header" />
</div>

```tsx
<Dialog>
  <DialogContainer>
    <DialogHeader>
      <DialogTitle>New Project</DialogTitle>
      <DialogDescription>
        Name the project and choose who owns it.
      </DialogDescription>
    </DialogHeader>
  </DialogContainer>
</Dialog>
```

## Head a Card or Section

1. For a title with See All, use [Card Content Header](/components/card-content-header) in a card or [Section Heading](/components/section-heading) on a page.
2. For a title with a description, put `text-section` on the heading, the description directly under it, and any buttons at `size="sm"` in the title's row, vertically centred on the title.

<div className="my-4">
  <TypographyDemo example="card-header" />
</div>

```tsx
<Card>
  <CardContent>
    <div className="flex flex-col">
      <div className="flex items-center justify-between gap-4">
        <h2 className="text-section">Storage</h2>
        <Button variant="tertiary" size="sm">
          Manage
        </Button>
      </div>
      <p className="text-body text-text-secondary">
        Files uploaded to this project
      </p>
    </div>
  </CardContent>
</Card>
```

## Long Text

- Titles wrap. Use `truncate` only in a tight row that shows the full text another way, such as a tooltip, and give that row `min-w-0`.
- Body text wraps. Keep running text to about 65 characters a line, with `max-w-prose`.

## Numbers

Use `tabular-nums` where numbers line up in a column, such as table cells, counts and metrics.

## Accessibility

Sizes are in rem, so text grows with the browser's zoom and font size. They don't change with screen width. Caption, 12, is the smallest size for text people need to read.

## Merging Classes

To combine classes in your app, use Equality's `cn`. It knows the text styles, so a colour beside one, such as `text-text-secondary`, doesn't remove it. Import it from `@eqtylab/equality/cn`: it loads no CSS, so it also works in tests and scripts that run without a bundler.

```ts
import { cn } from "@eqtylab/equality/cn";

<p className={cn("text-caption", "text-text-secondary")}>Joined 3 days ago</p>;
```

`text-title` is deprecated: use `text-title-1`. 8.0 removes it.

## Do and Don't

- Don't size a heading with `text-2xl`, `text-3xl` or a similar size, or add `font-bold`. Use one of the styles.
- Don't use `text-display-2` or `text-display-1` in app screens.
- Don't put `text-title-1` inside a card or dialog.
