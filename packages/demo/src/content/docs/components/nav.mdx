## Overview

Nav builds sidebars. `NavRail` holds an app's largest areas as icons, and `NavPanel` beside it holds the current area's pages, with a `NavSwitcher` in its header. Every row goes to a page. When one list can't hold them all, a row drills in or expands.

### Which One to Use

| You want to                                                           | Use                          | For example                                       | Not for                                                                    |
| --------------------------------------------------------------------- | ---------------------------- | ------------------------------------------------- | -------------------------------------------------------------------------- |
| Go to a page                                                          | [A row in a group](#groups)  | Dashboard, Indicators                             | Actions, such as Log out: use a [Dropdown Menu](/components/dropdown-menu) |
| Change to another one of the thing you're in                          | [`NavSwitcher`](#switcher)   | Another project                                   | Filtering a page: use a [Select](/components/select)                       |
| Go into something with its own pages, where other rows stop mattering | [Drill in](#drill-in)        | A policy, an agent's run, an app's Settings pages | A few views of one screen: use [Tabs](/components/tabs)                    |
| Browse pages grouped by topic                                         | [Expand](#expandable-groups) | A docs site's folders, at any depth               | An area people work inside: [drill in](#drill-in)                          |
| Move between an app's largest areas                                   | [`NavRail`](#usage)          | Projects, Agents, Library                         | An app with one area                                                       |

### Links and Routers

`href` makes a plain link. With a router, pass its link through `asChild`, so the page doesn't reload. A drill row needs neither. Set `current` from the route.

```jsx
<NavListItem label="Indicators" current={pathname === "/indicators"} asChild>
  <Link to="/indicators" />
</NavListItem>
```

`target="_blank"` opens the row in a new tab, with a ↗.

```jsx
<NavListItem
  label="Status Page"
  href="https://status.eqtylab.io"
  target="_blank"
/>
```

### Prefix and Suffix

`prefix` takes an icon. `suffix` takes a status or count as `Badge size="sm"`, and screen readers read it with the label.

<NavListDemo client:only="react" variant="prefix-suffix" />

```jsx
<NavListItem
  label="Applied Policies"
  prefix={<BookOpen />}
  suffix={<Badge size="sm">2</Badge>}
  href="/policies"
/>
```

## Switcher

`NavSwitcher` goes in the panel's `header` and shows the current item's name. Picking another item calls `onValueChange`, and your app goes to that item's top level. A level drilled into, such as a policy, belonged to the old item, so don't carry it across. `action` adds a command at the foot of the list.

<NavSwitcherDemo client:only="react" />

```tsx
const projectOptions = projects.map((p) => ({ value: p.id, label: p.name }));

<NavSwitcher
  label={project.name}
  noun="project"
  collection="projects"
  options={projectOptions}
  value={project.id}
  onValueChange={switchProject}
  action={{ label: "Create Project", onSelect: openCreateProject }}
/>;
```

### When the List Fails to Load

Pass `error` and `onRetry`, and the list offers Retry. Pass `retrying` while it reloads.

```tsx
const projects = projectsQuery.data ?? [];
const projectOptions = projects.map((p) => ({ value: p.id, label: p.name }));

<NavSwitcher
  {...props}
  options={projectOptions}
  error={projectsQuery.isError}
  retrying={projectsQuery.isFetching}
  onRetry={() => projectsQuery.refetch()}
/>;
```

## Drill-in

A row with `drill` opens the `NavDrillLevel` with that `value`. A level with a `parent` gets a ‹ row that goes back. Levels are direct children of `NavDrill`. Put the list on a background colour, like a panel or sheet, or the levels show through as they slide.

### Uncontrolled

Set the first level with `defaultValue`. Use it where the URL doesn't change, like a popover or sheet.

<NavListDemo client:only="react" variant="drill" />

```jsx
<NavList>
  <NavDrill defaultValue="project">
    <NavDrillLevel value="project">
      <NavListGroup label="Applied Policies">
        <NavListItem
          label="EU AI Act"
          prefix={<BookOpen />}
          drill="eu-ai-act"
        />
      </NavListGroup>
    </NavDrillLevel>
    <NavDrillLevel value="eu-ai-act" parent="project" label="EU AI Act">
      <NavListGroup>
        <NavListItem
          label="Controls"
          prefix={<Layers />}
          href="/policies/eu-ai-act/controls"
        />
      </NavListGroup>
    </NavDrillLevel>
  </NavDrill>
</NavList>
```

### Controlled by the URL

In an app, set `value` from the URL, so Back and bookmarks open the right level. `onValueChange` gets the level a click asks for: navigate there.

```jsx
const { policy } = useParams();
const navigate = useNavigate();

function openLevel(level) {
  navigate(level === "project" ? "/project" : `/policies/${level}`);
}

<NavDrill value={policy ?? "project"} onValueChange={openLevel}>
  …
</NavDrill>;
```

```tsx
const { projectId, policyId } = useParams();
const { pathname } = useLocation();
const navigate = useNavigate();
const base = `/projects/${projectId}`;
const policy = policies.find((item) => item.id === policyId);
const projectOptions = projects.map((p) => ({ value: p.id, label: p.name }));

      <Link to="/agents" />
    </NavRailItem>
  </NavRail>
  <NavPanel
    aria-label={
      policy ? `Applied Policy: ${policy.name}` : `Project: ${project.name}`
    }
    header={
      <NavSwitcher
        label={project.name}
        noun="project"
        collection="projects"
        options={projectOptions}
        value={project.id}
        onValueChange={(id) => navigate(`/projects/${id}`)}
      />
    }
  >
    <NavList>
      <NavDrill value={policy?.id ?? "project"} onValueChange={goToLevel}>
        <NavDrillLevel value="project">
          <NavListGroup label="Project">
            <NavListItem
              label="Dashboard"
              prefix={<LayoutGrid />}
              current={pathname === base}
              asChild
            >
              <Link to={base} />
            </NavListItem>
          </NavListGroup>
          <NavListGroup label="Applied Policies">
            {policies.map((item) => (
              <NavListItem
                key={item.id}
                label={item.name}
                prefix={<BookOpen />}
                drill={item.id}
              />
            ))}
          </NavListGroup>
        </NavDrillLevel>
        {policy && (
          <NavDrillLevel
            value={policy.id}
            parent="project"
            label={policy.name}
            backLabel={`${policy.name}, back to ${project.name}`}
          >
            <NavListGroup>
              <NavListItem label="Controls" prefix={<Layers />} asChild>
                <Link to={`${base}/policies/${policy.id}/controls`} />
              </NavListItem>
            </NavListGroup>
          </NavDrillLevel>
        )}
      </NavDrill>
    </NavList>
  </NavPanel>
  <main>…</main>
</div>;
```

### Docs Sidebar

Rows built from a tree of folders and pages. Folders around the `current` row open themselves. `@eqtylab/docs` builds its sidebar this way.

<NavListDemo client:only="react" variant="docs-sidebar" />

```tsx
function Rows({ nodes, top = false }) {
  const { pathname } = useLocation();
  return nodes.map((node) => {
    const prefix = top && node.icon ? <Icon icon={node.icon} /> : undefined;
    const suffix = node.badge && <Badge size="sm">{node.badge}</Badge>;
    return node.children ? (
      <NavListExpandable key={node.id}>
        <NavListExpandableTrigger
          label={node.label}
          prefix={prefix}
          suffix={suffix}
        />
        <NavListExpandableContent>
          <Rows nodes={node.children} />
        </NavListExpandableContent>
      </NavListExpandable>
    ) : (
      <NavListItem
        key={node.id}
        label={node.label}
        href={node.href}
        current={node.href === pathname}
        prefix={prefix}
        suffix={suffix}
      />
    );
  });
}
```

## Best Practices

### Pages, Not Actions

Every row takes the reader somewhere. Put actions elsewhere: Log Out in a [Dropdown Menu](/components/dropdown-menu), Create Project in the switcher's `action`. A reader who clicks a row expects to go somewhere, not to change something.

<NavListDemo client:only="react" variant="do-dont-actions" />

### Statuses and Counts in the Suffix

Use `Badge size="sm"`. Screen readers skip the prefix, and a badge there pushes the label out of line.

<NavListDemo client:only="react" variant="do-dont-status" />

### Icons on Every Top-Level Row, or None

Mixed icons make the labels zigzag.

<NavListDemo client:only="react" variant="do-dont-icons" />

### Don't Restyle Rows

A row with its own colours or sizes reads as an error, or as a different control. To change every row on a site, set the `--eq-list-item-*` variables.

<NavListDemo client:only="react" variant="do-dont-styling" />

### Don't Add Your Own Arrows

The row adds them itself: › when you set `drill`, ↗ when you set `target="_blank"`.

### Server-Rendered Pages: Start the Current Folder Open

Pass `defaultOpen` to the folder holding the current page, so it's open before the page's scripts load.

### Put a Folder's Own Page Inside It

A folder's header only opens and closes the folder; it can't link to a page. If the folder has a page of its own, add it as the first row inside, such as Overview.

### Name the Rail and Panel for What They Hold

Screen readers list `NavRail` and `NavPanel` as navigation landmarks by their `aria-label`. Use names that tell them apart, like "Main" and `` `Project: ${project.name}` ``.

## Slots

| Name                       | Description                                           |
| -------------------------- | ----------------------------------------------------- |
| `NavRail`                  | The column of icon links                              |
| `NavRailItem`              | An icon link in the rail, with its label as a tooltip |
| `NavPanel`                 | The sidebar panel, with a `header`                    |
| `NavSwitcher`              | Switches between items, in the panel's header         |
| `NavList`                  | Root of the rows                                      |
| `NavListGroup`             | A list of rows, with an optional label                |
| `NavListItem`              | A row: a link, or a button for a drill row            |
| `NavListSeparator`         | Divider between kinds of group                        |
| `NavListExpandable`        | A folder that opens and closes                        |
| `NavListExpandableTrigger` | The folder's header row                               |
| `NavListExpandableContent` | The folder's rows                                     |
| `NavDrill`                 | Shows one level at a time and slides between them     |
| `NavDrillLevel`            | One level of a drill-in, with its ‹ row               |

## Props

`NavList`, `NavListSeparator` and `NavListExpandableContent` take no props of their own.

### NavRail

| Name         | Description               | Type     | Default | Required |
| ------------ | ------------------------- | -------- | ------- | -------- |
| `aria-label` | Names the rail's landmark | `string` |         | ✅       |

### NavRailItem

| Name      | Description                                       | Type        | Default | Required          |
| --------- | ------------------------------------------------- | ----------- | ------- | ----------------- |
| `icon`    | The item's only visible content                   | `ReactNode` |         | ✅                |
| `label`   | The item's accessible name and its tooltip        | `string`    |         | ✅                |
| `href`    | Where the item goes                               | `string`    |         | Without `asChild` |
| `current` | Marks the current area                            | `boolean`   | `false` | ❌                |
| `asChild` | Renders the item as its child, like a router link | `boolean`   | `false` | ❌                |

### NavPanel

| Name         | Description                                  | Type        | Default | Required |
| ------------ | -------------------------------------------- | ----------- | ------- | -------- |
| `aria-label` | Names the panel's landmark                   | `string`    |         | ✅       |
| `header`     | Above the rows: a `NavSwitcher` or a heading | `ReactNode` |         | ❌       |

### NavSwitcher

| Name             | Description                                                                         | Type                                      | Default | Required     |
| ---------------- | ----------------------------------------------------------------------------------- | ----------------------------------------- | ------- | ------------ |
| `label`          | The current item's name, shown as the panel's heading                               | `string`                                  |         | ✅           |
| `noun`           | Singular, for the trigger's name: `{label}, switch {noun}`                          | `string`                                  |         | ✅           |
| `collection`     | Plural, for the search and empty copy                                               | `string`                                  |         | ✅           |
| `options`        | The items to switch between                                                         | `{ value, label, keywords? }[]`           |         | ✅           |
| `value`          | The current item's value                                                            | `string`                                  |         | ✅           |
| `onValueChange`  | Called with the picked item's value                                                 | `(value: string) => void`                 |         | ✅           |
| `onHighlight`    | Hover or focus on an option, to preload its page                                    | `(value: string) => void`                 |         | ❌           |
| `onHighlightEnd` | Hover or focus leaves an option, to cancel the preload                              | `() => void`                              |         | ❌           |
| `action`         | A command at the foot of the list, kept while searching; runs after the list closes | `{ label: string; onSelect: () => void }` |         | ❌           |
| `error`          | The list failed to load, and offers Retry                                           | `boolean`                                 | `false` | ❌           |
| `retrying`       | A retry is running, and the Retry row says so                                       | `boolean`                                 | `false` | ❌           |
| `onRetry`        | Called when Retry is picked                                                         | `() => void`                              |         | With `error` |
| `loading`        | Holds the switcher's height while the current item loads                            | `boolean`                                 | `false` | ❌           |

With `loading`, pass no other props. With no `options`, `action` or `error`, it's a plain heading.

### NavListGroup

| Name    | Description            | Type     | Default | Required |

### NavListItem

| Name            | Description                                                                                          | Type        | Default | Required |

| `prefix`        | An icon before the label; top-level rows only                                                        | `ReactNode` |         | ❌       |
| `suffix`        | A status or count after the label, read with it                                                      | `ReactNode` |         | ❌       |
| `drill`         | The level this row opens; adds ›                                                                     | `string`    |         | ❌       |
| `asChild`       | Renders the row as its child, like a router link                                                     | `boolean`   | `false` | ❌       |

| -------- | ------------------------------------------------ | ----------- | ------- | -------- |
| `label`  | The folder's name                                | `string`    |         | ✅       |
| `prefix` | An icon before the label; top-level folders only | `ReactNode` |         | ❌       |
| `suffix` | A status or count after the label, read with it  | `ReactNode` |         | ❌       |

### NavDrill

| Name            | Description                                                         | Type                                                  | Default | Required |
| --------------- | ------------------------------------------------------------------- | ----------------------------------------------------- | ------- | -------- |
| `value`         | Controlled: the current level                                       | `string`                                              |         | ❌       |
| `defaultValue`  | Uncontrolled: the first level                                       | `string`                                              |         | ❌       |
| `onValueChange` | Called when a drill row or ‹ asks for a level; `request` says which | `(value: string, request: "drill" \| "back") => void` |         | ❌       |

### NavDrillLevel

| Name        | Description                                          | Type     | Default         | Required      |
| ----------- | ---------------------------------------------------- | -------- | --------------- | ------------- |
| `value`     | The `NavDrill` value that shows it                   | `string` |                 | ✅            |
| `parent`    | The `value` ‹ returns to; adds the ‹ row             | `string` |                 | ❌            |
| `label`     | Names where you are, on the ‹ row                    | `string` |                 | With `parent` |
| `backLabel` | The ‹ row's accessible name; must start with `label` | `string` | `{label}, back` | ❌            |
