import {
  CardContentHeader,
  Card,
  CardContent,
  CardDescription,
} from "@eqtylab/equality";

## Overview

Card Content Header is a header row for the top of a card's content, pairing an icon on a square tile with a heading and an optional "See All" action button. It is designed to sit inside [CardContent](/components/card), giving grouped content a consistent title treatment.

It is [Title Block](/components/title-block)'s small size with a "See All" action. Reach for Title Block when you need a description, a different trailing item or a person's avatar.

The component renders nothing unless a `heading` or an `onButtonClick` handler is provided. When `onButtonClick` is set, a tertiary "See All" button sits at the end of the heading's line. The icon and heading stay side by side at every width: a long heading wraps beside the icon, never under it.

## Usage

Import the component:

```tsx
import { CardContentHeader } from "@eqtylab/equality";
```

Basic usage with the required `icon` and a heading:

```tsx
<CardContentHeader icon="SquareChartGantt" heading="Activity Logs" />
```

The `icon` prop accepts either a [Lucide](https://lucide.dev/icons/) icon name or a React element, and is rendered on a square tile.

## Variants

### Default

<CardContent client:only="react">
  <CardContentHeader
    icon="SquareChartGantt"
    heading="Activity Logs"
    onButtonClick={() => {}}
  />
</CardContent>

### Inside Card

<Card client:only="react">
  <CardContent className="space-y-2">

    />

```tsx

  </CardContent>

```

## Props

| Name            | Description                                                                               | Type                     | Default | Required |
| --------------- | ----------------------------------------------------------------------------------------- | ------------------------ | ------- | -------- |
| `icon`          | Icon shown on the square tile. A Lucide icon name or a React element.                     | `string`, `ReactElement` | —       | ✅       |
| `heading`       | Heading text rendered as an `h3`.                                                         | `string`                 | —       | ❌       |
| `onButtonClick` | Handler for the "See All" button. Providing it renders the button and adjusts the layout. | `() => void`             | —       | ❌       |

> **Note:** The component renders `null` when neither `heading` nor `onButtonClick` is provided, since there would be nothing meaningful to show.
