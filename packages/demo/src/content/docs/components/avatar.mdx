## Overview

Avatars represent a user or entity with a profile image and initials fallback. Give the fallback the full initials; small avatars show the first one, and screen readers still hear them all. A count such as `+3` shows whole at every size.

## Usage

Import the component:

```ts
import { Avatar, AvatarImage, AvatarFallback } from "@eqtylab/equality";
```

Basic usage with an image and fallback:

```tsx
<Avatar>
  <AvatarImage src="/path/to/image.jpg" alt="User name" />
  <AvatarFallback>AB</AvatarFallback>
</Avatar>
```

## Sizes

Leave `size` off in rows and in text. The default avatar is as tall as the line of text it sits in, so it fits a table, menu or list row without making it taller. Pass a size when the avatar stands beside a control or on its own: each size is as tall as the control of the same name.

<AvatarSizesDemo client:only="react" />

| Size          | Pixels            | Use it                                                                                                                                        | Initials |
| ------------- | ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| none (`line`) | As tall as a line | In a list or row with one line per person, even inside a card, or inside a line of text                                                       | One      |
| `xs`          | 24                | Beside an extra-small control                                                                                                                 | One      |
| `sm`          | 28                | Beside a small control                                                                                                                        | One      |
| `md`          | 36                | A person on their own: in a card or page header, an "Assigned to" field, or beside a name with a line under it. Also beside a default control | Two      |
| `lg`          | 44                | Beside a large control, or in a profile header                                                                                                | Two      |
| `xl`          | 52                | A profile or page hero: the largest person on a page                                                                                          | Two      |

```tsx
<Avatar>...</Avatar>
<Avatar size="xs">...</Avatar>
<Avatar size="sm">...</Avatar>
<Avatar size="md">...</Avatar>
<Avatar size="lg">...</Avatar>
<Avatar size="xl">...</Avatar>
```

### Beside a control

Match the avatar's size to the control's, so the two line up in a header or toolbar. A default control takes `size="md"`.

<AvatarControlDemo client:only="react" />

```tsx
<div className="flex items-center gap-2">
  <SearchBar searchQuery={query} setSearchQuery={setQuery} />
  <Avatar size="md">...</Avatar>
</div>
```

### In a row

Use the default avatar, with no `size`, in a `Table` cell or in a `DropdownMenu`, `Select` or `Command` item, at either table density. The row keeps its height, so rows with and without avatars line up.

<AvatarRowDemo client:only="react" />

<AvatarRowDemo client:only="react" variant="menu" />

<AvatarRowDemo client:only="react" variant="select" />

```tsx
<TableCell>
  <div className="flex items-center gap-2">
    <Avatar aria-hidden>
      <AvatarFallback>AC</AvatarFallback>
    </Avatar>
    Alice Cooper
  </div>
</TableCell>
```

In a `Select` item, wrap the avatar and the name the same way, and give the item a `textValue` so it matches on the name:

```tsx
<SelectItem value="alice" textValue="Alice Cooper">
  <span className="flex items-center gap-2">
    <Avatar aria-hidden>
      <AvatarFallback>AC</AvatarFallback>
    </Avatar>
    Alice Cooper
  </span>
</SelectItem>
```

When the name sits beside the avatar, hide the avatar from screen readers with `aria-hidden` so the name is not read twice.

## Slots

| Name       | Description                                            |
| ---------- | ------------------------------------------------------ |
| `children` | Accepts `AvatarImage` and `AvatarFallback` as children |

## Props

### Avatar

| Name    | Description             | Type                                 | Default  | Required |
| ------- | ----------------------- | ------------------------------------ | -------- | -------- |
| `size`  | The size of the avatar  | `line`, `xs`, `sm`, `md`, `lg`, `xl` | `line`   | ❌       |
| `shape` | The shape of the avatar | `circle`, `square`                   | `circle` | ❌       |

### AvatarImage

| Name  | Description                   | Type     | Default | Required |
| ----- | ----------------------------- | -------- | ------- | -------- |
| `src` | The image source URL          | `string` | -       | ❌       |
| `alt` | Accessible alt text for image | `string` | -       | ❌       |

### AvatarFallback

No properties, but needs child content to render.
