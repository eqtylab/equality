## Overview

`Menu` is a list of rows that stays on screen: a sidebar, a settings list, the contents of a popover or drawer. Each row is a link when it has `href` or `asChild`, and a button otherwise. The current page's row carries `aria-current="page"`.

Use `Menu` for lists that stay on screen and [DropdownMenu](/components/dropdown-menu) for pop-up menus of actions. `Menu` has no `role="menu"`: its rows are ordinary links and buttons, reached with <kbd>Tab</kbd>.

A `MenuDrill` turns a menu into levels that slide in and out: a row with `drill` opens a level, and the ‹ row at its top goes back. The [Nav](/components/nav) sidebar is built from these parts.

## Usage

Import the parts:

```tsx
import { Menu, MenuGroup, MenuItem, MenuList } from "@eqtylab/equality";
```

Every row sits in a `MenuList`, and a `MenuGroup` gives a list its label:

```tsx
<Menu>
  <MenuGroup label="Governance">
    <MenuList>
      <MenuItem label="Applied Policies" href="/policies" current />
      <MenuItem label="Agents" href="/agents" />
    </MenuList>
  </MenuGroup>
</Menu>
```

With a router, pass its link through `asChild`:

```tsx
<MenuItem label="Agents" asChild>
  <Link to="/agents" />
</MenuItem>
```

## Variants

### Groups and separators

A labelled group names its list for screen readers. Leave the label off where nothing needs naming. A `MenuSeparator` divides groups; it hides itself as the first or last child.

<MenuGroupsDemo client:only="react" />

```tsx
<Menu>
  <MenuGroup>
    <MenuList>
      <MenuItem label="Dashboard" prefix={<LayoutGrid />} href="/" current />
    </MenuList>
  </MenuGroup>
  <MenuGroup label="Governance">
    <MenuList>
      <MenuItem
        label="Applied Policies"
        prefix={<BookOpen />}
        suffix={<Badge size="sm">3</Badge>}
        href="/policies"
      />
    </MenuList>
  </MenuGroup>
  <MenuSeparator />
  <MenuGroup>
    <MenuList>
      <MenuItem label="Settings" prefix={<Settings />} href="/settings" />
    </MenuList>
  </MenuGroup>
</Menu>
```

### Prefix and suffix

`prefix` holds an icon before the label; screen readers skip it. `suffix` holds badges and marks after the label, and screen readers read it as part of the row, so a count or a status is heard. Hide a decorative icon in the suffix with `aria-hidden`.

The › caret comes from `drill`, never from `suffix`.

### Nesting

A nested list goes in a bare `<li>`, with a `MenuGroup` for its label. Its tree line is the list's left edge. Under rows with icons, the child rows' text lines up under their parent's text; without icons they indent 12px. Only top-level rows carry icons, and nesting stops at two levels: deeper content drills in instead.

<MenuNestingDemo client:only="react" />

```tsx
<MenuList>
  <MenuItem label="Overview" prefix={<LayoutGrid />} href="/components" />
  <li>
    <MenuGroup label="Forms">
      <MenuList>
        <MenuItem label="Input" href="/components/input" current />
      </MenuList>
    </MenuGroup>
  </li>
</MenuList>
```

### Size

`size` sets the row height for every list inside: `md` rows are 36px and `sm` rows 32px. Text, icons, padding and the gaps stay the same.

<MenuSizesDemo client:only="react" />

```tsx
<Menu size="sm">…</Menu>
```

### Touch

Under a coarse pointer, rows grow to a 44px tap target. To get the same in a touch surface that a fine pointer may also use, such as a phone drawer, set `--touch-target` on its container:

<MenuTouchDemo client:only="react" />

```tsx
<div style={{ "--touch-target": "2.75rem" }}>
  <Menu>…</Menu>
</div>
```

### Drill-in

`MenuDrill` shows one `MenuDrillLevel` at a time: the one whose `value` matches the view. A row with `drill` opens a level, and `MenuBackButton` returns to the level's `parent`, which also works after a deep link. Levels slide only after a drill row or ‹ asked for them; any other change, such as the browser's Back button, swaps them at once, as does reduced motion.

After a drill, focus moves to ‹. After ‹, it moves to the row you came from, or else to the current row.

Levels must be direct children of `MenuDrill`. A level wrapped in another component is not found.

#### In a popover

<MenuDrillPopoverDemo client:only="react" />

#### In a drawer

<MenuDrillDrawerDemo client:only="react" />

```tsx
<Menu>
  <MenuDrill defaultView="projects">
    <MenuDrillLevel value="projects">
      <MenuList>
        <MenuItem label="Ben Project" drill="ben" />
      </MenuList>
    </MenuDrillLevel>
    <MenuDrillLevel value="ben" parent="projects">
      <MenuBackButton
        label="Ben Project"
        aria-label="Ben Project, back to Projects"
      />
      <MenuList>
        <MenuItem label="Dashboard" href="/projects/ben" />
      </MenuList>
    </MenuDrillLevel>
  </MenuDrill>
</Menu>
```

#### Controlled

Pass `view` to hold the level yourself. `onViewChange` receives the level asked for and whether the request was a `drill` or a `back`; nothing changes until you set `view`. A drill row that is a router link can navigate, and `view` follows the route. Setting `view` without a request swaps the level without motion.

<MenuDrillControlledDemo client:only="react" />

```tsx
const [view, setView] = useState("projects");

<MenuDrill view={view} onViewChange={(next, request) => setView(next)}>
  …
</MenuDrill>;
```

## Slots

| Name     | Description                                                                   |
| -------- | ----------------------------------------------------------------------------- |
| `prefix` | An icon before the label, on top-level rows only. Hidden from screen readers. |
| `suffix` | Badges or marks after the label. Read by screen readers as part of the row.   |

## Props

### Menu

| Name   | Description                      | Type       | Default | Required |
| ------ | -------------------------------- | ---------- | ------- | -------- |
| `size` | Row height for every list inside | `md`, `sm` | `md`    | ❌       |

### MenuGroup

| Name    | Description                                                               | Type     | Default | Required |
| ------- | ------------------------------------------------------------------------- | -------- | ------- | -------- |
| `label` | Names the group's list; leave it out where a ‹ row already names the rows | `string` |         | ❌       |

### MenuItem

| Name      | Description                                              | Type        | Default | Required |
| --------- | -------------------------------------------------------- | ----------- | ------- | -------- |
| `label`   | The row's text, also its title when it truncates         | `string`    |         | ✅       |
| `href`    | Makes the row a link                                     | `string`    |         | ❌       |
| `current` | Marks the row as the page on show                        | `boolean`   | `false` | ❌       |
| `prefix`  | An icon before the label                                 | `ReactNode` |         | ❌       |
| `suffix`  | Badges or marks after the label                          | `ReactNode` |         | ❌       |
| `drill`   | The view of the level this row opens; adds ›             | `string`    |         | ❌       |
| `asChild` | Renders the row as its only child, such as a router link | `boolean`   | `false` | ❌       |

`MenuList` and `MenuSeparator` take their element's attributes only.

### MenuDrill

| Name           | Description                                           | Type                                                 | Default | Required |
| -------------- | ----------------------------------------------------- | ---------------------------------------------------- | ------- | -------- |
| `view`         | The level on show, when you hold it                   | `string`                                             |         | ❌       |
| `defaultView`  | The level shown first, when `MenuDrill` holds it      | `string`                                             |         | ❌       |
| `onViewChange` | Called when a drill row or ‹ asks for a level         | `(view: string, request: "drill" \| "back") => void` |         | ❌       |
| `animate`      | Slides levels after a request; off swaps them at once | `boolean`                                            | `true`  | ❌       |

### MenuDrillLevel

| Name     | Description            | Type     | Default | Required |
| -------- | ---------------------- | -------- | ------- | -------- |
| `value`  | The view that shows it | `string` |         | ✅       |
| `parent` | The view ‹ returns to  | `string` |         | ❌       |

### MenuBackButton

| Name    | Description                                             | Type     | Default | Required |
| ------- | ------------------------------------------------------- | -------- | ------- | -------- |
| `label` | Names where you are; an `aria-label` must start with it | `string` |         | ✅       |

## Sizes

Parts read their sizes from these variables in `theme/decisions.css`. `size="sm"` changes only the row height.

| Variable                 | Value             | Sets                                  |
| ------------------------ | ----------------- | ------------------------------------- |
| `--list-item-height`     | 36px (`sm`: 32px) | Row height                            |
| `--list-item-padding-x`  | 8px               | Row padding                           |
| `--list-item-gap`        | 8px               | Icon to text                          |
| `--list-item-icon-size`  | 16px              | Prefix, suffix and caret icons        |
| `--list-item-font-size`  | 14px              | Row text                              |
| `--list-gap`             | 2px               | Between rows                          |
| `--list-group-gap`       | 12px              | Above a group label and a separator   |
| `--list-label-gap`       | 4px               | Label to its first row                |
| `--list-label-font-size` | 12px              | Group label text                      |
| `--list-indent`          | 12px              | Child indent under rows without icons |
| `--control-height`       | 40px              | A rail item                           |
| `--touch-target`         | 0, 44px on touch  | Minimum row and rail item height      |
